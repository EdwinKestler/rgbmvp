TESTNET ONLY

Run a demo swap

Triggers a real Bitcoin ↔ Liquid testnet HTLC atomic swap and shows it settle on-chain, step by step.

  • Testnet only. No real value moves. Mainnet is refused by the software itself.
  • The swap runs between this lab's own wallets — not yours. You are triggering a demonstration, not trading.
  • Capped. Small fixed amounts, a daily limit, and a total fee budget for the run.
  • It may pause. Testnet coins come from faucets; when a wallet runs low the demo stops until it is refilled.
  • Bitcoin confirmations pace the swap. Testnet blocks are irregular — a run can take anywhere from minutes to over an hour.
